# Automated Short-Answer Grading: accuracy vs. transferability

MSc thesis project (Information Science, University of Amsterdam, 2023) comparing
embedding-based models, fine-tuned BERT, and GPT-3.5-turbo as short-answer graders
across five public datasets under one evaluation protocol.

Full write-up in progress. The thesis is at [docs/thesis.pdf](docs/thesis.pdf),
dataset instructions at [data/README.md](data/README.md).
